# Backend

## Getting Started

**Make sure you have python 3.13 installed before following this**

1. Clone the repo
2. Open the terminal and **change to this directory**
```bash
cd backend
```
3. Create a virtual environment using python
```bash
python -m venv .venv
```
4. Load/activate into the virtual environment
```bash
# on Linux
source .venv/bin/activate
# or on Windows
./.venv/Scripts/activate
```
5. Enjoy Programming!
